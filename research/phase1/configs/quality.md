# 第一阶段质量判定

本文件只定义候选相对参考如何归类。样本数、题目评分和基线能力下限见 [data.md](data.md)。哪一步做筛选见 [../guide.md](../guide.md)。本文件与 guide.md 共同定义当前实验约定。这里的容差不是第二阶段的正式 $\epsilon_{t,S}$。

分数为 0–100。下降 = 参考 − 候选。开发筛选容差为 2 分。每个候选同时相对高精度和登记的 KV8 比较。接近已经退化的 KV8，不能单独作为过线理由。

先算下降和区间，再归入下表的一种状态。

| 状态 | 定义 | 归入之后 |
|---|---|---|
| 开发晋级 | 点估计与区间都已登记 | 可以进入下一步。不能写成质量通过或保留 |
| 保留 | 相对高精度与 KV8，下降区间上界均 ≤ 2，且无分项系统性失效 | 具备最终候选资格 |
| 淘汰 | 下降区间下界 > 2，或实现、格式不可行 | 停止该配置 |
| 证据不足 | 区间跨越 2；分层样本不足以判断时同样使用 | 最终候选可扩样；仍跨越则保持这一状态 |

## 区间

区间在开跑前冻结种子：

- 二值任务：配对分歧计数。两类分歧概率用精确二项区间，再以 Bonferroni 合成保守 95% 区间。
- 连续分数：样本级配对重采样，固定 10,000 次和随机种子。全零差异不报告退化的零宽区间。
- 同一样本的多个 token 不作为独立样本。结果写下样本数、分歧数、分项分数和区间。

## 扩样

二值任务在零分歧时，保守上界大约是：n = 64 为 6–7 分，n = 128 为 3–4 分，n = 256 为 1.7 分。因此 n = 64 不能标成保留。保留只用于 guide.md 的最终候选与扩样所定最终候选扩到 128、最多 256 之后。扩样顺序为 64→128→256。扩样时，对应参考和用于比较的随机配置一起扩。出现 1 题分歧即容易超过 2 分。V 上的结论仍是开发证据。

已冻结的做法：起始样本量保持 data.md 的划分，二值任务与连续分数使用同一 2 分容差。

分层结果以诊断为主。本阶段的区间用于开发决策，不作为最终非劣性证明。

## 类通过

条件是一种表示加上残留精度 $H$。真实生成与误差来源的筛选、残留和长解码都用这一条，不另定通过标准。

| 类 | 单元 |
|---|---|
| 短生成 | V 的 GSM8K |
| 检索 | V 的 32K 检索；V 的 32K 多证据问答。两个单元分开记录 |
| 长解码 | 真实生成与误差来源第 7 步里，四问联答 BF16 实际生成达到 256 token 的请求；各条件用同一请求子集。四题先平均，不足 256 token 的请求按 data.md 单独计数。统计单位为请求，报告写明 $n \le 16$；历史单问保持原协议。量化候选提前结束、缺少答案或触及生成上限时，仍按当次评分留在该子集 |

某一类在该条件下类通过，当且仅当每个参加判断的单元都未淘汰，而且该单元相对高精度、相对 KV8 的下降点估计都 ≤ 2。单元淘汰指：该单元格式不可行，或这两个下降里有一个区间下界 > 2。类通过不写成保留。新检索按题配对；四问联答先平均请求内四题，再在上述 BF16 请求子集上计算区间。

高精度基线未达 data.md 下限的单元不参加判断。某一类没有参加判断的单元时，该类不归类。

单元下降点估计是该单元两个下降点估计中的较大者。长问答和长解码的下降用 token-F1，EM 只记录。短生成和 32K 检索用 data.md 的 EM。

状态表仍照常登记。开发晋级或证据不足不等于类通过。

静态 Key 分配的 C 预算—KL 比较只登记各模型、格式、预算的方案级证据。
严格低于三个随机方案不授予类通过或保留，不触发自动 V 选择。
当前没有预先验证的通用 KL 质量合格线；开发生成筛选与后续 V 计划须分别冻结，
其冻结状态在 static_layer_allocation.json 登记。

## 静态分配最终候选

候选、参考与任务只由 static_layer_allocation.json 的 v_plan 冻结。三个单题任务
按 64→128→256 累计；四问联答按 long_decode.json 的 16→32→64 请求累计，
统计单位为请求。各轮沿用 BF16 生成达到 256 token 的同一请求子集，须非空且
BF16 请求均值 F1≥40；候选提前结束、缺答案或触及上限均计入配对。

相对 BF16 与 KV8 的下降区间上界均≤2，且无分项系统性失效，完成规定最终
扩样后才授予保留；任一区间下界>2 或实现、格式不可行记淘汰；区间跨越2、
端点缺失或有效样本不足记证据不足。全零连续差异保留缺失区间，不给零宽区间。
仅仍有最终候选价值且证据不足的任务扩样，不新增随机或保护随机的 V 测量。
已核对的首轮参考直接复用；BF16、KV8 只追加缺少的扩样题，K8V4 不强制同步扩样。
某个必要任务淘汰后停止该候选进一步扩样，但三候选均完成四单元首轮。
Llama 优先全层 KV4；低成本候选获得全部单元保留后，混合备选因候选收敛停止，
不登记为淘汰。上限仍不确定或基线不足时据实收尾。区间继续是开发决策证据。

## 无效组

无效组的判定见 quant.md。出现无效组的样本记 0 分，保留在配对中，并单独计数。同一任务单元内这种样本达到 2 个时，该配置按格式不可行淘汰。误差比较不删除该样本。选择最低误差时，留出折上出现过无效组的表示，排在所有没有无效组的表示之后。
