## 范围

本阶段只改变 KV 表示，并测量数值误差、存储、追加写入和读出成本。任务质量实验保持全历史 dense Attention。这里的“检索”指长距离信息检索题；retrieval 路径和页选择器不在本阶段。

| 纳入 | 不纳入 |
|---|---|
| 现成 GQA 模型上的均匀 INT4/INT8、K/V 不对称、layer × K/V 静态位宽 | streaming/retrieval head、路径分派、sink 或窗口驱逐、页评分与 top-k、稀疏访问搜索、RTL |
| 分组完成前的高精度缓冲、近期 INT8/FP16 残留、静态逐 token 标签的布局回放 | INT2、非均匀码本、稀疏异常值支路、GEAR、MiniCache、TurboQuant 完整量化器、GTA/GLA |
| 固定物理块上的打包、反量化、RoPE 和两段矩阵的读出核算 | 新的硬件架构 |

表示的定义见 [configs/quant.md](configs/quant.md)。本阶段按下面的身份使用它们。诊断项不自动成为主候选。

| 表示 | 本阶段身份 |
|---|---|
| Key 离线 per-channel、在线 per-token | 主候选 |
| Key 在线跨 token | 诊断。依赖高精度历史缓冲时，不能标成无残留主候选 |
| 近期高精度残留 | 只在真实生成与误差来源使用 |

基线是同权重、同位置编码的全量 BF16/FP16 KV，以及均匀 KV8、均匀 KV4。后两者就是主矩阵里「在线 per-token、post-RoPE」那两格，不另开条件。比较一个因素时，其余数值和缓存规则不变。质量实验在短上下文上诊断，在 32K 上做迁移。128K 只进入存储与服务成本，两模型都只做布局计数。

## 要回答的问题

| 问题 | 通过时要留下的证据 |

## 执行顺序

`configs/runtime.md` 的准入清单按实测填完之后，再执行：

```text
环境与高精度冒烟
  → 数据清单与 splits/（见 data.md，不运行量化候选）
  → 参考正确性（未通过则停止后续质量结论）
  → 位宽与表示交互（两模型共同的四种 K8V4 进入真实生成与误差来源）
  → 真实生成与误差来源（每模型选定 1 种表示进入静态层分配）
  → 静态层分配
  → 最终候选与扩样
  → 存储与服务成本
  → 整理结果并覆盖回传
```

先 Qwen，再 Llama。同一现象最多追加一组能区分原因的对照。没有主候选通过时，记录失败条件，不自动扩展到 INT2、训练或更多模型。

## 写代码时要遵守的约束

环境与高精度冒烟、参考正确性都用这一组约束。存储与服务成本实验把 pre-RoPE 的读时旋转计入成本。

| 约束 | 要求 |
|---|---|
| 全序列词表 logits | Prefill 不物化全部位置的词表 logits。使用 `num_logits_to_keep=1` 或只保留末位。下文的 logit 指送入 softmax 的注意力分数，不是词表 logit。 |
| 注意力路径 | decode 的 score、softmax、累加和反量化目的类型见 data.md。位宽与表示交互的层内误差走同一条路径。 |
| 非方形因果掩码 | query 长度为 1 时，`is_causal=True` 会套用错误掩码。使用 `is_causal=False` 或显式掩码，使单 token 看见全部有效历史。 |
| pre-RoPE | 从旋转前直接取 Key，不做逆旋转。decode 时对历史 Key 重新施加 RoPE。 |
| 长输入中间量 | 不保存完整注意力矩阵和全部位置的词表 logits。轨迹按层保存预登记位置与统计量。 |

## 环境与高精度冒烟

按 [configs/runtime.md](configs/runtime.md) 建立环境，核对模型清单，并在两款模型上做短输入、4K、32K 的高精度冒烟。冒烟代码满足上一节约束。

记录：GPU、显存、BF16 是否可用、prefill 与单步 decode 的时延和峰值显存。峰值含权重、激活和工作区。32K 不可达时记下最大可达长度，不改协议。

通过：两模型短输入冒烟成功，32K 成功或已记录不可达原因，并且 runtime.md 的准入清单已按实测填写。一次性结果先审核，准入事实与来源写入 `configs/runtime.md` 后，清理临时代码、输出与独立报告。

## 参考正确性

排除实现假象。未通过则不做位宽与表示交互–存储与服务成本的质量结论。在合成边界值和少量真实 KV 上核对：

| 检查 | 通过标准 |
|---|---|
| 实现约束 | 上一节各条约束成立；pre-RoPE 与 post-RoPE 在同一输入上的对照一致 |
| 往返 | 量化—打包—解包—反量化与手算的小张量一致 |
| 布局 | KV8、KV4、K8V4、K4V8 可按 quant.md 的打包规则计数 |
| 边界 | 常量组、超界、未满组、刚闭合组、整块、尾块、非有限值、scale 下溢、参数溢出都有明确结果 |
| 账本 | 手算结果与 quant.md 的三本账逐项一致 |
| 长度 | 短输入先定位，再抽样 32K 的掩码和 prefill/decode 交界 |

这不算任务质量通过。一次性检查的准入状态、覆盖范围与来源写入 `configs/runtime.md`；没有未解决失败后清理临时代码与结果。需要持续保障的回归用例保留在 `research/tests/`，共享实现保留在 `research/src/kvstudy/` 与阶段公共模块中。

## 位宽与表示交互

每格所有层用同一配置。每层以高精度轨迹的隐藏状态为输入，单独计算本层误差，误差不向后传播。下表没有列出的项用 quant.md 的默认数值。主矩阵里的 Value，以及 Key 的在线 per-token 一档，都用该默认，包括 $G_c$ 和参数格式。评估题、两折、离线 scale 的拟合折和 query 位置见 data.md。

| 因素 | 取值 |
|---|---|
| Key | 离线 per-channel；在线 per-token |
| RoPE | pre-RoPE；post-RoPE |
| 位宽 | KV8、K8V4、K4V8、KV4 |

每模型主矩阵 16 个条件。pre-RoPE 与 post-RoPE 用同一批 C 数据分别校准。

主矩阵保留注意力输出相对平方误差 $\|\Delta o\|^2/\|o\|^2$、无效组和容量。$\|o\|^2=0$ 的层单独计数，不进入平均。每题先平均有效层，再对两折等权汇总。无效组按 quality.md 处理。补充归因统一使用下面的配对指标，停止维护旧的重建尾部、正态形状摘要、经验各向同性方差预测和全网 next-token KL 支线。

每个模型另加一格 Value 分组诊断。它不进入主矩阵，也不占追加名额。这一格与主矩阵中「KV4、Key 离线 per-channel、pre-RoPE」配对，只把 Value 改为离线 per-channel，校准折与 Key 相同，其余用 quant.md 默认。它只记录注意力输出相对误差、无效组和容量，不补重建、尾部、饱和率、分数或概率的误差链。它用于检查 Value 分组，不进入当前真实生成候选集。

### 配对归因的测量与判读

配对传播诊断的参数只在 [configs/representation_diagnostics.json](configs/representation_diagnostics.json) 登记。它只增加观测，不改冻结样本、量化规则和主矩阵；诊断补测本身不改变候选。当前候选范围的调整另按下文执行。修改观测配置时直接更新该文件，并重测受影响的诊断；结果中的测量格式标识用于区分实际保存的指标。两模型已完成全部四组配对传播测量，具体结果和审核记录见位宽与表示交互的统一结果与报告。后续新增指标仍须先明确标为待测。

四组 Key 方式 × RoPE 条件分别配对。K8、K4、V8、V4 从同一高精度输入直接量化；不把 K8 再量化到 K4。Q、首个生成 token、历史位置和离线参数拟合折固定。记 $p_8=\operatorname{softmax}(s_8)$、$p_4=\operatorname{softmax}(s_4)$、$\delta s=s_4-s_8$，输出 $o_{88}=V_8^\top p_8$、$o_{48}=V_8^\top p_4$、$o_{84}=V_4^\top p_8$；$o_{\rm HF}$ 是同轨迹高精度参考。指标无需假设残差为高斯或独立噪声。

| 要回答的问题 | 必测量 | 判读方式 |
|---|---|---|
| K 降位宽是否比 V 更影响输出 | $D_K=\|o_{48}-o_{88}\|^2/\|o_{\rm HF}\|^2$、$D_V=\|o_{84}-o_{88}\|^2/\|o_{\rm HF}\|^2$；逐题 $D_K-D_V$、正值题数、均值的配对 bootstrap 95% 区间 | 差值区间是否高于零、方向是否跨题/表示/模型一致；不凭单个总体均值外推 |
| 注意力权重改变多少 | $W=\sum_i p_{8,i}(\delta s_i-\sum_jp_{8,j}\delta s_j)^2$；$D_{\rm KL}(p_8\|p_4)$；$\operatorname{TV}=\tfrac12\|p_4-p_8\|_1$ | 同条件配对看中位数、p90/p99；检查 KL 与 $W/2$ 的偏离，不设通用 KL 合格线 |
| 输出变化能否由一阶传播解释 | $\widehat{\delta o}_K=\sum_i p_{8,i}(v_{8,i}-o_{88})\delta s_i$；预测与实测增量的相对残差、长度比、余弦 | 残差相对实际 K 增量小、长度比和余弦接近 1 才支持局部一阶解释；零向量用 null 和标记，不塞入极小分母 |
| 哪些位置的竞争受到影响 | 预先按 $p_8$ 选择 top-k；基准间隔 $s_{8,i}-s_{8,j}$、残差差 $\delta s_i-\delta s_j$、$\|v_{8,i}-v_{8,j}\|^2$、排序翻转率、选中概率覆盖率 | 联合看重要位置的相对分数变化和 Value 差异；覆盖率低时只解释该子集；配对贡献范数不能相加当作总输出误差 |

辅助保留中心化分数 MSE 以对接已有证据。L1 与 TV 是同一量的两种尺度，不算两份独立证据。均匀中心化只用于展示，不是 softmax 的额外步骤。概率指标在每个 query head 上计算；输出指标先对整层所有 head 求总能量再归一化。头和层都是同题的重复测量，置信区间只在题目级、两折内重采样，条件于已拟合的互补折参数，不包含重新拟合校准参数的波动。分位数也以逐题均值为单位，不能和旧的全 head 上尾混用。

保留输出误差闭合检查：令 $b=o_{88}-o_{\rm HF}$，则 $E_{48}-E_{84}=D_K-D_V+2b^\top[(o_{48}-o_{88})-(o_{84}-o_{88})]/\|o_{\rm HF}\|^2$。报告交叉项及闭合残差，防止把 KV8 的基线误差误算成 K 或 V 的降位宽增量。主矩阵维持既有 FP32 注意力路径；配对传播诊断使用同一份 FP32 Q、反量化 K/V，以 FP64 计算分数、概率和解释指标，数值口径登记在来源中。早期配对输出诊断保留原数值，不能标成已补测传播指标。

### 文件与唯一运行入口

位宽与表示交互的 `code/evaluate.py` 负责捕获、互补折校准和运行；`metrics.py` 定义指标；`results.py` 审核、题级统计和导出；`select.py` 保留候选筛选。其他实验共用的捕获与量化辅助接口放在 `src/phase1/representation.py`。每模型仅保留 `results/<model>/summary.json` 与 `samples.json`：前者合并主矩阵、配对汇总、来源及测量状态，后者保存 96 题 × 4 条件的配对小型评分。详细逐层记录与位置对留在服务器，由路径和 SHA256 索引。

在服务器项目根目录，发布已提交的本地代码后运行，先 Qwen 再 Llama：

```bash
PYTHONPATH=research/src:research/phase1/src:research/phase1 \
  research/.runtime/env/py311/bin/python \
  -m experiments.representation_interactions.code.evaluate qwen --commit <本地提交号>
```

默认只补测配对指标，读取并保留冻结主矩阵和当时的候选记录。`--summarize-only` 从已完成的配对传播详细记录重新审核导出，不做模型前向；早期配对输出详细记录不能补出未保存的指标。只有显式 `--refresh-matrix` 才重测 16 格及 Value 诊断、按当前规则登记候选并更新 all-C 校准；使用这一选项后须复核依赖位宽与表示交互的真实生成与误差来源结果。真实生成入口从完整主矩阵按当前规则取得四种候选，不沿用历史 `kept` 的两个名额，因此仅扩大候选范围不要求重测已有数值矩阵。正式运行不写报告，回传审核后再更新报告。

追加只围绕主矩阵已出现的差异，从下列项里选，不全部交叉。主矩阵与追加合计不超过 32：跨 token 的 $G_t \in \{32,64,128\}$、$G_c \in \{64,128\}$、FP8 参数。追加格只用于解释，不参加下面的选择。位宽与表示交互只算数值误差，$G_t$ 不受块长限制；进入真实生成与误差来源或存储与服务成本的 $G_t$ 须整除所用物理块长。

通过：结合两个模型的两折平均注意力输出相对误差与完整容量，保留 K8V4 的全部四种表示，即 Key 离线 per-channel／在线 per-token × pre／post-RoPE；Value 均为在线 per-token。现有八组配对中 K8V4 的局部输出误差均小于 K4V8，四种 K8V4 的完整容量也均低于同模型均匀 KV8。两模型使用同一候选集，不按模型分别取前两名，也不把局部误差的细小排名解释为生成能力排名。完整容量须严格低于均匀 KV8，测量缺失或容量不满足时停止候选登记并记录原因，不静默缩减共同候选集。KV4 与 KV8 保留为均匀基线，其他 KV4 格、K4V8 和 Value 分组格留作本实验的数值对照。结果写入 `experiments/representation_interactions/results/`。

## 真实生成与误差来源

主比较为高精度、KV8、KV4，加上位宽与表示交互留下的四种 K8V4；两模型使用完全相同的表示条件。生成、划分、评分和基线能力用 data.md。状态用 quality.md。

已有正式结果仅覆盖历史候选集：Qwen 已测四种 K8V4 中的离线 per-channel、post-RoPE，需补其余三种；Llama 已测在线 per-token 的 pre／post-RoPE，需补离线 per-channel 的两种。原评分、输入校验值、提前停止和选择记录保持实际运行时的含义。补测使用同一冻结 V、生成与评分设置，离线候选使用全部 C 的对应 RoPE 校准参数。输入、代码路径或校准内容有影响结果的变化时，受影响的参考与候选一并重跑。四种候选在参加判断的单元上补齐，或留下满足原判据的严重失效提前停止记录后，才重新执行第 5 步及其依赖的残留、层分配和成本判断；已有结论不能视为新候选集上的最终选择。

1. C 上真实生成。某一单元的高精度基线未达 data.md 的下限时，该单元停止量化结论。
2. V 的短任务，全部在 $H=0$ 下运行。状态按 quality.md 登记。
3. V 的 32K 检索和多证据问答，全部在 $H=0$ 下运行。记录实际长度和停止原因。第 5 步的 $H=0$ 复用第 2、3 步，不重跑。
4. 离线 scale：用全部 C 重新拟合，不沿用位宽与表示交互的单折 scale，在 V 上冻结。可用少量高精度快照判断重新估计范围能否解释误差。不用 V 重校准，也不据此更新候选。
5. 先选定一种低位宽表示，再只对它补跑残留。低位宽指主比较里除高精度和 KV8 以外的表示。在参加判断的单元上都未淘汰的低位宽表示中，按 quality.md 的单元下降点估计，取各单元最大值最小者；相同则取完整字节更少的。这一步只用 $H=0$。全部淘汰时，静态层分配使用均匀 KV8，不补跑残留。选定之后只补跑 $H=8$ 和 $H=16$，范围是 V 的短生成、32K 检索和 32K 多证据问答三个单元，每模型多 2 个配置。$R=128$。副本的写入、读取和滑出见 quant.md。$H=16$ 与权重浮点相同。$H=8$ 为均匀非对称、在线 per-token、$G_c=32$，Key 和 Value 都是 8 bit。$H=0$ 不保留副本。三种 $H$ 的低位宽主存都由同一高精度值量化。不继续搜 $R$。近期残留与序列开头的 sink 分开记录。

第 5 步只对短生成和检索两类判断残留。类通过见 quality.md。某一类在 $H=0$ 下不类通过、在某个 $H>0$ 下类通过，该类记为依赖缓冲，并算作被挽回。$H=0$ 已经类通过的类记为无残留可行；残留只使分数更高，不算拉开。能让所有被挽回的类都类通过的最小 $H$，就是拉开质量的残留精度，静态层分配带这个 $H$。没有被挽回的类，或者没有一个 $H>0$ 能同时让它们都类通过时，静态层分配不带残留。某一类在 $H=0$、$H=8$ 和 $H=16$ 下都不类通过时，记为有无残留都不可行。
6. 每模型一个跨 token 组格式：$G_t=32$，位宽与第 5 步选定的表示相同，只把 Key 换成在线跨 token；第 5 步全部淘汰时用 KV4 的位宽。记录组内位置和闭合前后的误差。轨迹必须跨过组边界。
7. 少量预登记轨迹：单层干预、固定 token 的全层回放、自由生成。自由生成一旦分歧，不再把隐藏状态差当作同一输入上的量化误差。检索轨迹的范围见 data.md。在这些轨迹上按层、按 KV head 汇总注意力输出误差，保存预登记位置的统计量。记录误差集中在少数 head，还是摊在整层。本阶段不做路径分派。
8. 长历史与长解码的交点。材料、长度和评分见 data.md。只在第 5 步选定的那一种表示上运行，并补跑高精度和 KV8 两个参照；第 5 步全部淘汰时跳过这一步。残留一侧使用第 5 步的残留精度；第 5 步没有这种 $H$ 时，诊断用 $H=16$。$H=0$ 与这一残留精度各自按 quality.md 的类通过判断长解码，不看第 5 步有没有拉开质量。$H=0$ 类通过，记为无残留可行。$H=0$ 不通过而残留精度类通过，记为依赖缓冲。结果写明 $n \le 8$，只作诊断。第 8 步不改静态层分配的表示，也不改静态层分配是否带残留。

严重失效的配置保留记录，不强制跑完后续组合。初始 V 的主比较计划规模为每模型 7 个配置 × 3 组 × 64 题，都是 $H=0$；基线未达下限的单元只记录失败边界。第 5 步补跑的 2 个配置和第 8 步不计入这个规模。

通过：给出进入静态层分配的一种表示。归类对象是第 5 步选定的表示；全部淘汰时不归类，只记失败边界。短生成、检索和长解码分开归类，每类取一种：无残留可行、依赖缓冲、有无残留都不可行；该类没有参加判断的单元时记为未归类。三类可以不同。前三种只按第 5、8 步的类通过归入。有无残留都不可行的类，可另附诊断标签「范围失配」或「局部误差不能解释累计失败」，并写明依据来自第 4 步快照还是第 7 步轨迹；标签不参与任何选择。是否带残留只由第 5 步决定。无残留可行的对象是本阶段 INT4/INT8 工作点。离线 scale 的证据范围是全部 C 拟合、V 上评估。结果写入 `experiments/generation_error_sources/results/`。

## 静态层分配

固定真实生成与误差来源选定的一种表示。真实生成与误差来源第 5 步定下的残留精度在本实验的全部分配里一致使用，并计入完整字节。分配单位是（层，K）和（层，V），位宽只取 INT4 或 INT8。Llama 有 64 个单位，Qwen 有 56 个。均匀 KV4 失败不是开始本实验的前提。

敏感度是局部量。探针把被测单位设为 INT4，该层其余单位保持高精度轨迹里的值，输入用高精度轨迹的隐藏状态。分数是注意力输出相对误差 $\|\Delta o\|^2/\|o\|^2$，在 data.md 的 query 位置上对 KV head 取平均。数学子集和检索子集分开排名。分配使用检索排名。两条排名前一半单位的交集不到一半时，在结果里写明。重建分配使用同一探针下的相对重建误差 $\|\Delta x\|^2/\|x\|^2$。

两个预算点是 25% 与 50% 的单位为 INT8。K 与 V 的元素数相同，这就是元素预算。主预算是 50%。按完整 KV 字节核查。每个预算点的分配是：

- 按检索敏感度，把 INT8 分给误差最高的单位
- 按相对重建误差，把 INT8 分给误差最高的单位
- 把 INT8 分给检索敏感度最低的单位
- 3 个固定种子：同样数量的 INT8 单位均匀随机放置
- 适用的均匀 KV8/KV4，以及全网 K8V4/K4V8

进入 V 之前，把准备比较的分配一次加到全部单位上，在同一条前向里计算预登记 query 位置的 next-token KL。是否送入 V 只看检索子集，数学子集只记录。门槛只在主预算上判断：敏感度分配的 KL 须严格小于全部 3 个随机分配，才算通过。通过时，送入 V 的两个非随机分配是敏感度分配和「INT8 给低敏感单位」。未通过时，改为重建分配和「INT8 给低敏感单位」。

主预算上，上述 2 个非随机分配加上 3 个随机分配，进入 V 的短任务与 32K。另一预算点只在 C 上做成本取舍。V 的排序只解释迁移，不回头改本阶段已经冻结的配置。字节不能精确对齐时，用同一成本上限并写下差额。真实生成与误差来源留下的按 head 误差随结果保存。

V 上的判断以检索类两个单元相对高精度的下降点估计为准。敏感度分配在这两个单元上都低于全部 3 个随机分配时，记为优于随机；否则记静态层混合证据不足。各分配的状态照常按 quality.md 登记。

通过：敏感度分配未通过 C 上的门槛，或在 V 上没有优于随机时，记下静态层混合的证据不足，保留更简单的候选。结果写入 `experiments/static_layer_allocation/results/`。

## 最终候选与扩样

静态层分配之后、存储与服务成本之前，每模型确定最终候选：

- 真实生成与误差来源选定的表示，带第 5 步的残留精度；
- 敏感度分配通过了 C 上的门槛时，静态层分配主预算上送入 V 的两个非随机分配中，检索类两个单元最大下降点估计较小的一个；
- 真实生成与误差来源的低位宽全部淘汰时，第一项换成均匀 KV8，只相对高精度比较。

对每个最终候选，在参加判断的每个 V 单元上，下降区间跨越 2 的按 quality.md 以 64→128→256 扩样。高精度和 KV8 参照随之扩样；候选来自静态层分配时，3 个随机分配也一起扩。扩样题取 data.md 的扩样池，按 `splits/` 的顺序追加。扩到 256 仍跨越时记证据不足。长解码诊断不扩样。状态按 quality.md 重新登记，结果写入 `experiments/static_layer_allocation/results/expanded_quality/`。选择文件是存储与服务成本包的唯一最终候选输入。

## 存储与服务成本

在质量候选和必要的失败对照上做有限扫描。测量区间是连续 256 个 decode 步，与按任务停止的质量实验分开。字节、名义位宽、算术强度和带宽下界按 quant.md 计算。

| 轴 | 取值 |
|---|---|
| 长度 | 4K、32K、128K（128K 只做布局计数，无质量结论） |
| Batch | B = 1 必做；B = 4 只做一个代表条件：Llama、32K、物理块 64、真实生成与误差来源选定的表示（全部淘汰时用 KV8） |
| 物理块 | 32、64、128 token |

三组对照：同样元素位宽下比较参数组织；同样精度比例下比较按层连续布局和静态逐 token 标签；比较 KV8、K8V4、K4V8、KV4 的读出代价。标签布局不运行 token 显著性算法。没有实测带宽时，用 0.1、1、3.35 TB/s 三档假设；主结论是名义位宽排序发生翻转的带宽阈值，三档只作示例。

结果写入 `experiments/storage_service_cost/results/`：容量与传输前沿、服务时间模型，以及下一阶段要遵守的格式约束。约束表至少记下：

- pre-RoPE 的读时旋转是否改变 $T_{\mathrm{shared,lb}}$ 与 $T_{\mathrm{split,lb}}$ 的排序；
- 物理块长是不是所用 $G_t$ 的整数倍；未满组以高精度参与 Attention 时，是否已按残留计入三本账；
- K 与 V 分存时，分通道下界是否短于共享带宽下界；
- scale 与浮点偏移在 4K 和 128K 各占传输的比例，名义位宽排序在哪一档带宽假设下翻转；
- 残留区在本工作点上是第二种静态精度，还是可以不用；
- 层混合相对均匀 K8V4 / KV4 的完整字节差，是否大到要按层切换数据通路。

128K 两模型都只做布局计数，不运行前向。Qwen 的配置窗口是 32K，本阶段也不扩窗。没有可靠能量依据时，只记访问和操作次数。

## 停止

| 条件 | 行动 |
|---|---|
| 参考正确性不正确 | 停止候选比较，先修实现 |
| 显存不足 | 减临时张量、分块或轨迹；不缩短上下文，不减少样本 |
| 高精度基线不足 | 记下缺口，修订配置后再比候选 |
| 区间跨越容差 | 最终候选按 quality.md 扩样；仍跨越则写证据不足 |
| 低位宽全部失败 | 保留 KV8 与高精度的结论和失败边界 |
| 出现新机制线索 | 写入该实验的结果；不扩大本阶段要完成的实验 |

## 结束时留下什么

每模型的最终候选按最终候选与扩样确定，至多 2 个，允许负结果。四项研究问题的证据、分项质量和失败记录留在对应的 `results/` 目录，并能追到代码版本和 `configs/`。

每个候选的结果至少登记：模型与 prefill/decode 协议；K/V 位宽、轴、$G_t$/$G_c$、scale 来源与格式、舍入与 RoPE；全网或 layer × K/V 分配及其校准来源；追加、未满组、尾块和残留副本；分任务质量、短生成、长解码和检索各自的真实生成与误差来源类别、按 KV head 汇总的检索误差，以及三本账；存储与服务成本约束表里适用于该候选的行；适用条件、失败条件和硬件假设。审核通过后，再按这些结果写报告。
