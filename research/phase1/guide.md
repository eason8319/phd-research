本文件规定本阶段做哪些实验、按什么顺序做、每一步怎样才算通过。

## 范围

本阶段只改变 KV 表示，并测量数值误差、存储、追加写入和读出成本。任务质量实验保持全历史 dense Attention。这里的“检索”指长距离信息检索题；retrieval 路径和页选择器不在本阶段。

| 纳入 | 不纳入 |
|---|---|
| 现成 GQA 模型上的均匀 INT4/INT8、K/V 不对称、layer × K/V 静态位宽 | streaming/retrieval head、路径分派、sink 或窗口驱逐、页评分与 top-k、稀疏访问搜索、RTL |
| 分组完成前的高精度缓冲、近期 INT8/FP16 残留、静态逐 token 标签的布局回放 | INT2、非均匀码本、稀疏异常值支路、GEAR、MiniCache、TurboQuant 完整量化器、GTA/GLA |
| 固定物理块上的打包、反量化、RoPE 和两段矩阵的读出核算 | 新的硬件架构 |

表示的定义见 [configs/quant.md](configs/quant.md)。本阶段按下面的身份使用它们。诊断项不自动成为主候选。

| 表示 | 本阶段身份 |
|---|---|
| Key 离线 per-channel、在线 per-token | 主候选 |
| Key 在线跨 token | 诊断。依赖高精度历史缓冲时，不能标成无残留主候选 |
| 近期高精度残留 | 只在 E2 使用 |

基线是同权重、同位置编码的全量 BF16/FP16 KV，以及均匀 KV8、均匀 KV4。后两者就是主矩阵里「在线 per-token、post-RoPE」那两格，不另开条件。比较一个因素时，其余数值和缓存规则不变。质量实验在短上下文上诊断，在 32K 上做迁移。128K 只进入 E4，两模型都只做布局计数。

## 要回答的问题

| 问题 | 通过时要留下的证据 |
|---|---|
| H1：Key 优先升位宽是否依赖量化轴、RoPE 和 scale 来源？ | K8V4 与 K4V8 是否换序；误差出现在重建、注意力分数、概率还是注意力输出。进入 E2 的依据是注意力输出相对误差 |
| H2：没有高精度历史缓冲的静态表示，何时还能保持质量？ | 离线 scale 漂移、组闭合误差、近期残留收益是否可分开。短生成、长解码和检索分开归类 |
| H3：短校准的层敏感度能否指导长上下文的静态分配？ | （层，K）与（层，V）的排序能否迁移；同等成本下是否优于全部随机分配。进入 V 前用全层同时干预复核 |
| H4：质量合格的低位宽表示，何时真正降低传输和服务时间？ | 名义位宽排序与实际字节、服务时间排序是否不同 |

负结果有效。四个问题不要求都出现有利发现。尚未运行、因资源省略和已证伪分开记录。

## 执行顺序

`configs/runtime.md` 的准入清单按实测填完之后，再执行：

```text
M0 环境与高精度冒烟
  → 数据清单与 splits/（见 data.md，不运行量化候选）
  → E0 正确性（未通过则停止后续质量结论）
  → E1 局部表示（每模型最多 2 种非基线表示进入 E2）
  → E2 真实生成与 32K（每模型选定 1 种表示进入 E3）
  → E3 静态层分配
  → F 最终候选与扩样
  → E4 成本
  → 整理结果并覆盖回传
```

先 Qwen，再 Llama。同一现象最多追加一组能区分原因的对照。没有主候选通过时，记录失败条件，不自动扩展到 INT2、训练或更多模型。

## 写代码时要遵守的约束

M0 的冒烟和 E0 的核对都用这一组约束。E4 把 pre-RoPE 的读时旋转计入成本。

| 约束 | 要求 |
|---|---|
| 全序列词表 logits | Prefill 不物化全部位置的词表 logits。使用 `num_logits_to_keep=1` 或只保留末位。下文的 logit 指送入 softmax 的注意力分数，不是词表 logit。 |
| 注意力路径 | decode 的 score、softmax、累加和反量化目的类型见 data.md。E1 的层内误差走同一条路径。 |
| 非方形因果掩码 | query 长度为 1 时，`is_causal=True` 会套用错误掩码。使用 `is_causal=False` 或显式掩码，使单 token 看见全部有效历史。 |
| pre-RoPE | 从旋转前直接取 Key，不做逆旋转。decode 时对历史 Key 重新施加 RoPE。 |
| 长输入中间量 | 不保存完整注意力矩阵和全部位置的词表 logits。轨迹按层保存预登记位置与统计量。 |

通过：两模型短输入冒烟成功，32K 成功或已记录不可达原因，并且 runtime.md 的准入清单已按实测填写。结果写入 `results/m0/`。

## E1：位宽与表示的交互（H1）

每格所有层用同一配置。每层以高精度轨迹的隐藏状态为输入，单独计算本层误差，误差不向后传播。下表没有列出的项用 quant.md 的默认数值。主矩阵里的 Value，以及 Key 的在线 per-token 一档，都用该默认，包括 $G_c$ 和参数格式。评估题、两折、离线 scale 的拟合折和 query 位置见 data.md。

| 因素 | 取值 |
|---|---|
| Key | 离线 per-channel；在线 per-token |
| RoPE | pre-RoPE；post-RoPE |
| 位宽 | KV8、K8V4、K4V8、KV4 |

每模型主矩阵 16 个条件。pre-RoPE 与 post-RoPE 用同一批 C 数据分别校准。

这里的 logit 是缩放后、送入 softmax 的注意力分数。记录这条层内链：重建误差与尾部、饱和率、去掉公共偏移后的 logit 误差、每个 query head 的概率 KL 及其平均、注意力输出的相对误差 $\|\Delta o\|^2/\|o\|^2$。$\|o\|^2=0$ 的位置单独计数，不进入该层平均。层间取相对误差的平均。另外记录全层同时量化时、同一 query 位置的 next-token KL；这个数不参与选择。无效组按 quality.md 处理。

每个模型另加一格 Value 分组诊断。它不进入主矩阵，也不占追加名额。这一格与主矩阵中「KV4、Key 离线 per-channel、pre-RoPE」配对，只把 Value 改为离线 per-channel，校准折与 Key 相同，其余用 quant.md 默认。它参加下面的 4 bit 档，不另占名额。

追加只围绕主矩阵已出现的差异，从下列项里选，不全部交叉。主矩阵与追加合计不超过 32：跨 token 的 $G_t \in \{32,64,128\}$、$G_c \in \{64,128\}$、FP8 参数。追加格只用于解释，不参加下面的选择。E1 只算数值误差，$G_t$ 不受块长限制；进入 E2 或 E4 的 $G_t$ 须整除所用物理块长。

通过：用两折平均的注意力输出相对误差选择，容量有效位宽须严格低于均匀 KV8。6 bit 档是主矩阵里 K8V4、K4V8 的各格，留下误差最低的 1 种。4 bit 档是主矩阵里 KV4 的各格和 Value 分组诊断，留下误差最低、且严格低于均匀 KV4 的 1 种。误差相同则留下完整字节更少的。4 bit 档没有候选时，6 bit 档留下误差最低的 2 种。没有可留的非基线时，只记录失败条件。结果写入 `results/e1/`。

## E2：静态 scale、残留与误差来源（H2）

主比较为高精度、KV8、KV4，加上 E1 留下的至多 2 种表示。生成、划分、评分和基线能力用 data.md。状态用 quality.md。

1. C 上真实生成。某一单元的高精度基线未达 data.md 的下限时，该单元停止量化结论。
2. V 的短任务，全部在 $H=0$ 下运行。状态按 quality.md 登记。
3. V 的 32K 检索和多证据问答，全部在 $H=0$ 下运行。记录实际长度和停止原因。第 5 步的 $H=0$ 复用第 2、3 步，不重跑。
4. 离线 scale：用全部 C 重新拟合，不沿用 E1 的单折 scale，在 V 上冻结。可用少量高精度快照判断重新估计范围能否解释误差。不用 V 重校准，也不据此更新候选。
5. 先选定一种低位宽表示，再只对它补跑残留。低位宽指主比较里除高精度和 KV8 以外的表示。在参加判断的单元上都未淘汰的低位宽表示中，按 quality.md 的单元下降点估计，取各单元最大值最小者；相同则取完整字节更少的。这一步只用 $H=0$。全部淘汰时，E3 使用均匀 KV8，不补跑残留。选定之后只补跑 $H=8$ 和 $H=16$，范围是 V 的短生成、32K 检索和 32K 多证据问答三个单元，每模型多 2 个配置。$R=128$。副本的写入、读取和滑出见 quant.md。$H=16$ 与权重浮点相同。$H=8$ 为均匀非对称、在线 per-token、$G_c=32$，Key 和 Value 都是 8 bit。$H=0$ 不保留副本。三种 $H$ 的低位宽主存都由同一高精度值量化。不继续搜 $R$。近期残留与序列开头的 sink 分开记录。

第 5 步只对短生成和检索两类判断残留。类通过见 quality.md。某一类在 $H=0$ 下不类通过、在某个 $H>0$ 下类通过，该类记为依赖缓冲，并算作被挽回。$H=0$ 已经类通过的类记为无残留可行；残留只使分数更高，不算拉开。能让所有被挽回的类都类通过的最小 $H$，就是拉开质量的残留精度，E3 带这个 $H$。没有被挽回的类，或者没有一个 $H>0$ 能同时让它们都类通过时，E3 不带残留。某一类在 $H=0$、$H=8$ 和 $H=16$ 下都不类通过时，记为有无残留都不可行。
6. 每模型一个跨 token 组格式：$G_t=32$，位宽与第 5 步选定的表示相同，只把 Key 换成在线跨 token；第 5 步全部淘汰时用 KV4 的位宽。记录组内位置和闭合前后的误差。轨迹必须跨过组边界。
7. 少量预登记轨迹：单层干预、固定 token 的全层回放、自由生成。自由生成一旦分歧，不再把隐藏状态差当作同一输入上的量化误差。检索轨迹的范围见 data.md。在这些轨迹上按层、按 KV head 汇总注意力输出误差，保存预登记位置的统计量。记录误差集中在少数 head，还是摊在整层。本阶段不做路径分派。
8. 长历史与长解码的交点。材料、长度和评分见 data.md。只在第 5 步选定的那一种表示上运行，并补跑高精度和 KV8 两个参照；第 5 步全部淘汰时跳过这一步。残留一侧使用第 5 步的残留精度；第 5 步没有这种 $H$ 时，诊断用 $H=16$。$H=0$ 与这一残留精度各自按 quality.md 的类通过判断长解码，不看第 5 步有没有拉开质量。$H=0$ 类通过，记为无残留可行。$H=0$ 不通过而残留精度类通过，记为依赖缓冲。结果写明 $n \le 8$，只作诊断。第 8 步不改 E3 的表示，也不改 E3 是否带残留。

严重失效的配置保留记录，不强制跑完后续组合。初始 V 的主比较规模约为每模型 5 个配置 × 3 组 × 64 题，都是 $H=0$。第 5 步补跑的 2 个配置和第 8 步不计入这个规模。

通过：给出进入 E3 的一种表示。归类对象是第 5 步选定的表示；全部淘汰时不归类，只记失败边界。短生成、检索和长解码分开归类，每类取一种：无残留可行、依赖缓冲、有无残留都不可行；该类没有参加判断的单元时记为未归类。三类可以不同。前三种只按第 5、8 步的类通过归入。有无残留都不可行的类，可另附诊断标签「范围失配」或「局部误差不能解释累计失败」，并写明依据来自第 4 步快照还是第 7 步轨迹；标签不参与任何选择。是否带残留只由第 5 步决定。无残留可行的对象是本阶段 INT4/INT8 工作点。离线 scale 的证据范围是全部 C 拟合、V 上评估。结果写入 `results/e2/`。

## E3：静态层分配（H3）

固定 E2 选定的一种表示。E2 第 5 步定下的残留精度在本实验的全部分配里一致使用，并计入完整字节。分配单位是（层，K）和（层，V），位宽只取 INT4 或 INT8。Llama 有 64 个单位，Qwen 有 56 个。均匀 KV4 失败不是开始本实验的前提。

敏感度是局部量。探针把被测单位设为 INT4，该层其余单位保持高精度轨迹里的值，输入用高精度轨迹的隐藏状态。分数是注意力输出相对误差 $\|\Delta o\|^2/\|o\|^2$，在 data.md 的 query 位置上对 KV head 取平均。数学子集和检索子集分开排名。分配使用检索排名。两条排名前一半单位的交集不到一半时，在结果里写明。重建分配使用同一探针下的相对重建误差 $\|\Delta x\|^2/\|x\|^2$。

两个预算点是 25% 与 50% 的单位为 INT8。K 与 V 的元素数相同，这就是元素预算。主预算是 50%。按完整 KV 字节核查。每个预算点的分配是：

- 按检索敏感度，把 INT8 分给误差最高的单位
- 按相对重建误差，把 INT8 分给误差最高的单位
- 把 INT8 分给检索敏感度最低的单位
- 3 个固定种子：同样数量的 INT8 单位均匀随机放置
- 适用的均匀 KV8/KV4，以及全网 K8V4/K4V8

进入 V 之前，把准备比较的分配一次加到全部单位上，在同一条前向里计算预登记 query 位置的 next-token KL。是否送入 V 只看检索子集，数学子集只记录。门槛只在主预算上判断：敏感度分配的 KL 须严格小于全部 3 个随机分配，才算通过。通过时，送入 V 的两个非随机分配是敏感度分配和「INT8 给低敏感单位」。未通过时，改为重建分配和「INT8 给低敏感单位」。

主预算上，上述 2 个非随机分配加上 3 个随机分配，进入 V 的短任务与 32K。另一预算点只在 C 上做成本取舍。V 的排序只解释迁移，不回头改本阶段已经冻结的配置。字节不能精确对齐时，用同一成本上限并写下差额。E2 留下的按 head 误差随结果保存。

V 上的判断以检索类两个单元相对高精度的下降点估计为准。敏感度分配在这两个单元上都低于全部 3 个随机分配时，记为优于随机；否则记静态层混合证据不足。各分配的状态照常按 quality.md 登记。

通过：敏感度分配未通过 C 上的门槛，或在 V 上没有优于随机时，记下静态层混合的证据不足，保留更简单的候选。结果写入 `results/e3/`。

## F：最终候选与扩样

E3 之后、E4 之前，每模型确定最终候选：

- E2 选定的表示，带第 5 步的残留精度；
- 敏感度分配通过了 C 上的门槛时，E3 主预算上送入 V 的两个非随机分配中，检索类两个单元最大下降点估计较小的一个；
- E2 的低位宽全部淘汰时，第一项换成均匀 KV8，只相对高精度比较。

对每个最终候选，在参加判断的每个 V 单元上，下降区间跨越 2 的按 quality.md 以 64→128→256 扩样。高精度和 KV8 参照随之扩样；候选是 E3 分配时，3 个随机分配也一起扩。扩样题取 data.md 的扩样池，按 `splits/` 的顺序追加。扩到 256 仍跨越时记证据不足。长解码诊断不扩样。状态按 quality.md 重新登记，结果写入 `results/f/`。

## E4：成本何时改变排序（H4）

在质量候选和必要的失败对照上做有限扫描。测量区间是连续 256 个 decode 步，与按任务停止的质量实验分开。字节、名义位宽、算术强度和带宽下界按 quant.md 计算。

| 轴 | 取值 |
|---|---|
| 长度 | 4K、32K、128K（128K 只做布局计数，无质量结论） |
| Batch | B = 1 必做；B = 4 只做一个代表条件：Llama、32K、物理块 64、E2 选定的表示（全部淘汰时用 KV8） |
| 物理块 | 32、64、128 token |

三组对照：同样元素位宽下比较参数组织；同样精度比例下比较按层连续布局和静态逐 token 标签；比较 KV8、K8V4、K4V8、KV4 的读出代价。标签布局不运行 token 显著性算法。没有实测带宽时，用 0.1、1、3.35 TB/s 三档假设；主结论是名义位宽排序发生翻转的带宽阈值，三档只作示例。

结果写入 `results/e4/`：容量与传输前沿、服务时间模型，以及下一阶段要遵守的格式约束。约束表至少记下：

- pre-RoPE 的读时旋转是否改变 $T_{\mathrm{shared,lb}}$ 与 $T_{\mathrm{split,lb}}$ 的排序；
- 物理块长是不是所用 $G_t$ 的整数倍；未满组以高精度参与 Attention 时，是否已按残留计入三本账；
- K 与 V 分存时，分通道下界是否短于共享带宽下界；
- scale 与浮点偏移在 4K 和 128K 各占传输的比例，名义位宽排序在哪一档带宽假设下翻转；
- 残留区在本工作点上是第二种静态精度，还是可以不用；
- 层混合相对均匀 K8V4 / KV4 的完整字节差，是否大到要按层切换数据通路。

128K 两模型都只做布局计数，不运行前向。Qwen 的配置窗口是 32K，本阶段也不扩窗。没有可靠能量依据时，只记访问和操作次数。

## 停止

| 条件 | 行动 |
|---|---|
| E0 不正确 | 停止候选比较，先修实现 |
| 显存不足 | 减临时张量、分块或轨迹；不缩短上下文，不减少样本 |
| 高精度基线不足 | 记下缺口，修订配置后再比候选 |
| 区间跨越容差 | 最终候选按 quality.md 扩样；仍跨越则写证据不足 |
| 低位宽全部失败 | 保留 KV8 与高精度的结论和失败边界 |
| 出现新机制线索 | 写入该实验的结果；不扩大本阶段要完成的实验 |

## 结束时留下什么

每模型的最终候选按 F 确定，至多 2 个，允许负结果。H1–H4 的证据、分项质量和失败记录留在对应的 `results/` 目录，并能追到代码版本和 `configs/`。

每个候选的结果至少登记：模型与 prefill/decode 协议；K/V 位宽、轴、$G_t$/$G_c$、scale 来源与格式、舍入与 RoPE；全网或 layer × K/V 分配及其校准来源；追加、未满组、尾块和残留副本；分任务质量、短生成、长解码和检索各自的 H2 类别、按 KV head 汇总的检索误差，以及三本账；E4 约束表里适用于该候选的行；适用条件、失败条件和硬件假设。审核通过后，再按这些结果写报告。
