# Key 降位宽敏感度与静态层分配

本文检验局部 Key 敏感度能否识别降位宽代价，并转化为有价值的固定预算配置。Qwen 的关键层保护已有直接效果证据，精细排序的额外收益尚未建立；Llama 在当前检索任务上缺少可分辨的分配信号。更新日期：2026-10-12。

来源：[阶段指导](../../../guide.md)、[分配配置](../../../configs/static_layer_allocation.json)和[数值诊断配置](../../../configs/static_numerics.json)规定设计，[冻结检索清单](../../../splits/static_retrieval.json)规定输入。[执行代码](../code/)中的内容探针、完整路径、成本计数与数值诊断对应[正式结果](../results/)两模型的 probe.json、numerics_summary.json、allocations.json、numerical_allocations.json、numerical_questions/；历史评分见 rescoring.json，原始审核见 numerics_review.json。完整层表、逐题差异、预测、校准参数和执行来源由[阶段来源索引](../../../source_index.json)追溯。正式测量和负结果全部保留；补充图见[单层诊断](single_layer_prediction.png)、[全层 KL](key_budget_kl.png)、[生成正确率](key_budget_accuracy.png)、[完整路径](full_path_margins.png)、[绝对叠加残差](numerical_closure.png)及[叠加分布](logit_superposition.png)。

## 实验目的

两模型分别为 Qwen2.5-7B-Instruct（28 层）与 Llama-3.1-8B-Instruct（32 层）。Value 主存固定 INT4，三格式为在线 per-token pre/post-RoPE（H=0）和离线 per-channel pre-RoPE（H=8、R=128）。每模型检索校准、验证各 16 题；K4 层数分别为 Qwen 的 2/7/14 和 Llama 的 2/8/16，其余 K8。九种同预算策略为敏感度、重建、反向、三个随机及三个保护随机；各格式独立排名，随机集合随预算嵌套，验证题不参与层表生成。

第一项实验测量局部输出变化并核对单层端到端代价，第二项检验完整分配、自由生成和成本。内容 NLL 先题内 token 平均，再对题目等权平均，单位 nat/内容 token；预测后才输入当前目标 token，各方案持续更新自己的量化缓存。可靠差异按题目配对 bootstrap 95% 区间判断，重采样 10,000 次、种子由数值配置固定。在线 post 补齐当前实现、实际 FP32 输出头、FP32 残差与输出头三条件及两次重复，取逐题精度/重复差异的最小和最大值后重采样形成包络；其他格式使用当前实现的题目配对比较。主门槛仍为敏感度可靠低于全部三个随机策略。

## 实验结果与结论

### 不同表示下 Key 降位宽的层间代价

局部 $S$ 是同一高精度轨迹、同一 V4 下 K4V4 与 K8V4 注意力输出的相对平方变化，分母为共同 BF16 输出能量；K4、K8 从共同源直接量化，先平均有效 KV query 组，再平均内容位置与题目。下图来自校准探针，每模型 $n=16$，层号从 0 开始，单位为相对平方变化；实线为全部内容位置，虚线为首内容位置。

![三格式逐层 Key 降位宽敏感度](key_downgrade_layers.png)

Qwen 在线 pre/post 的最高敏感层均为第 0 层，最大与最小 $S$ 相差约 532、480 倍；离线 pre、H8 的高敏感层转向 26、27、23、25 等后部层。Llama 也有局部层间差异，但分布不同。首内容与全部内容排序相关均超过 0.93；敏感度与重建排名相关仅为 0.157–0.492，说明输出变化与 K 张量失真形成不同排序。pre 重建沿用读时旋转后主存、近期副本替换前的口径。

单层验证以同格式全层 K8V4 为 $B$，仅第 $\ell$ 层 K4 为 $A_\ell$，比较 $\Delta L_\ell=L(A_\ell)-L(B)$。以下为 Qwen 在线 post、验证 $n=16$；点估计采用当前实现，区间为三精度与题目重采样包络，单位 nat/内容 token。各精度基线内容正确均为 15/16。

| 降为 K4 的层 | 平均 ΔNLL | 95% 包络 | 内容正确数（三精度一致） |
| --- | ---: | ---: | ---: |
| 0 | 8.1422 | [6.7991, 9.7717] | 0/16 |
| 27 | 3.46e−6 | [2.84e−7, 7.87e−6] | 15/16 |

第 0 层同时出现可靠的大损失和生成崩溃，第 27 层虽有可分辨的损失增量，内容正确数保持不变。局部高敏感能够对应严重退化层，但局部扰动、内容损失与生成错误是不同的量。

Llama 在线 post 的全部 32 个单层配置没有形成可靠的内容代价信号。下表来自单层诊断，验证 $n=16$，两半为预先平衡的各 8 题；KL 参照为同精度 $B$，相关采用逐层点估计。

| 计算条件 | 两半 ΔNLL 排名相关 | 两半单层 KL 排名相关 | 可靠 ΔNLL 层数 |
| --- | ---: | ---: | ---: |
| 当前实现 | 0.135 | 0.114 | 0/32 |
| FP32 输出头 | −0.038 | 0.282 | 0/32 |
| FP32 残差与输出头 | 0.059 | 0.214 | 0/32 |

提高计算精度没有建立稳定的端到端层排序，当前任务尚不足以评价精细排序的预测能力。两次路径 logits 逐值一致只建立执行重复性；仅提升输出头几乎不改变绝对叠加残差，加入 FP32 残差后不闭合减少约一成，但未建立 $S$ 的端到端预测力。数值与叠加诊断作为测量解释保留。

### 不同预算下的 Key 位宽分配与全层验证

敏感度、重建分别将最低局部代价、最低 K4 重建误差的 $r$ 层降为 K4，反向选择最高 $S$ 的层；保护随机固定校准最高两层为 K8，再从原随机排列中选择其余 K4 层。全部位宽表在验证前冻结，各格式、预算的九策略 K8 数量与完整字节相同，相同配置复用测量。

下图为完整矩阵概览：两模型、三格式、三预算均保留，每格验证 $n=16$，当前实现，题均内容 NLL，单位 nat/内容 token；虚线为同格式全层 K8V4。

![完整分配的内容损失概览](key_budget_nll.png)

Qwen 在线包含第 0 层的反向方案，以及半层预算的随机 3，内容 NLL 约为 8–11，内容正确数均为 0/16；避开该层的多数方案 NLL 约为 $10^{-6}$，内容正确为 15/16 或 16/16。已有证据支持避免严重退化配置。

18 个工作点中，敏感度可靠低于全部三个随机的工作点为 **0/18**：在线 post 的六点包含完整精度包络，其余十二点依据当前实现的题目重采样。以下配对图展示在线 post、验证 $n=16$；点为当前均值，线段为三精度/重复的题目 bootstrap 95% 包络，横轴为敏感度减对照的 NLL（nat/token），跨零记为未分辨。

![同预算配对差异](paired_budget_comparison.png)

Qwen 在线 post 三档预算的敏感度都可靠低于反向和随机 3；小预算减随机 3 的包络为 $[-7.53\times10^{-6},-3.08\times10^{-7}]$，微小损失优势也可以分辨。它未可靠优于重建、随机 1/2 或三个保护随机。Llama 在线 post 的同预算比较均未分辨出差异。因此，避免失败的效果已建立，敏感度普遍优于同预算随机分配的证据尚未建立。

在线保护干预同时固定第 **0、27 层**为 K8。Qwen 半层预算随机 3 在 pre/post 两格式都由 0/16 恢复为 16/16；post 的内容 NLL 从 8.4963 降到 $9.12\times10^{-7}$。敏感度没有可靠优于三个保护随机，关键层保护解释了在线方案的主要收益，精细排序的额外收益尚未建立。

离线保护层为 26、27。保护随机 3 在七层预算的 NLL 为 $2.33\times10^{-4}$，保护随机 2 在半层预算为 $6.17\times10^{-4}$，对应敏感度约为 $1.02\times10^{-6}$、$1.04\times10^{-6}$；四套方案内容正确均为 15/16。离线仍有损失层面的配置差异，但未显示任务得分收益。

统一评分把检索内容与输出格式分开：去首尾空白，只接受完整 val-xxxxxxxx 或裸八位小写十六进制值，再精确匹配目标。Llama 所有已测完整配置和单层配置均为内容正确 **16/16**、完整形式合规 **10/16**；六条省略 val- 的回答取到了正确目标值，原严格 10/16 作为内容与形式同时正确的指标保留。

Qwen 的分隔符案例说明内容 NLL 还需结合完整路径。查询 key-909c1bd1，正确答案为 val-8b6b444a；本轮 BF16 在 val 后选择 -d 而非 -，生成 val-d694ade7。强制输入正确分隔符后，该题内容 NLL 仅为 $5.70\times10^{-9}$。在线 post 半层敏感度方案则沿正确路径生成正确答案。同题在不同设备执行中的参考结果发生变化：本轮 RTX 4090 BF16 为 15/16，历史 RTX 6000 Ada 为 16/16，方案效果与本轮参考配对。

完整路径记录正确 token 相对最强错误候选的领先量，覆盖前缀、分隔符、内容和终止。在相同缓存更新、无额外 logits 处理的贪心规则下，各步领先量严格为正时，规范路径与实际生成相符；偏离后独立评分替代输出。内容 teacher forcing、路径稳定性与自由生成正确率分别承担预测支持度、路径和任务结果的证据角色。

完整成本还需与更简单的低成本端点比较。下表来自冻结布局和完整验证，批量 1、32K，驻留容量包含主存、参数、对齐和近期副本，单位 MiB；端点内容正确数来自当前实现的 16 道验证题。在线 pre/post 的容量相同。

| 模型与格式 | 全层 K8V4 | 半层 K4 | 全层 KV4 | KV4 内容正确 |
| --- | ---: | ---: | ---: | ---: |
| Qwen，在线 pre/post | 784 | 672 | 560 | 0/16 |
| Qwen，离线 pre，H8 | 731.992 | 619.992 | 507.992 | 15/16 |
| Llama，在线 pre/post | 1792 | 1536 | 1280 | 16/16 |
| Llama，离线 pre，H8 | 1673.125 | 1417.125 | 1161.125 | 16/16 |

在线半层方案相对 K8V4 节省 14.3%，仍比全层 KV4 多占 20%；离线半层方案相对同格式起点节省约 15.3%，同时保留近期副本写入和 pre-RoPE 读时旋转成本。Qwen 在线混合精度有继续验证的依据；Llama 三格式 KV4 均保持 16/16，应作为竞争候选检验额外 K8 预算的价值。这里测得的是缓存容量和读写成本，尚未建立服务时间或系统加速收益。

新输入采用独立 key/value 和干扰值。八组替换映射检查中，Qwen 有 7/8 对、Llama 有 8/8 对内容均随映射改变；旧输入删除目标后仍可能输出共同后缀，支持修复数据构造。映射控制、重建误差、首内容位置、全词表 KL、逐题贡献和完整叠加诊断保留在集中来源中的详细记录。

## 总结

Qwen 在线局部敏感度识别出明确的严重退化层，保护校准最高两层能恢复失败方案；精细层排序尚未带来可靠的额外收益。Llama 当前检索任务缺少可分辨的单层和分配信号，内容正确与格式合规的差别已按统一规则更正。实验留下三格式排名、三预算九策略冻结配置、完整成本与匹配的预测/生成结果，正式测量和负结果全部保留。

下一步独立任务验证建议保留 Qwen 在线混合配置与两层保护随机对照，并把 Llama 全层 KV4、同格式 K8V4 和混合配置直接竞争，同时保留 BF16 与同输入 KV8 参照，检验额外高精度预算是否带来质量收益。进入 V 的格式、预算、策略数量与扩样规则另行冻结；这些是后续安排，尚未通过独立质量验证。
