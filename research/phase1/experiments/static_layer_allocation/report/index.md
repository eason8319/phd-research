# Key 降位宽敏感度与静态层分配

本文回答：固定 Value 主存为 INT4 时，局部 Key 降位宽敏感度能否预测真实的降位宽代价，并形成较好的固定预算分配？更新日期为 2026-10-09。测量对象为 Qwen2.5-7B-Instruct 与 Llama-3.1-8B-Instruct 的独立随机键值检索、正确答案内容位置预测、单层边际影响和完整分配方案。

来源说明：设计与冻结参数见 `research/phase1/guide.md`、`research/phase1/configs/static_layer_allocation.json`、`research/phase1/configs/quant.md`、`research/phase1/configs/runtime.md`；新检索清单为 `research/phase1/splits/static_retrieval.json`，保留原 C 的长度、深度和干扰数量。执行代码在 `research/phase1/experiments/static_layer_allocation/code/`：`content_data.py` 冻结独立映射及实际分词，`content.py` 完成探针、分配、内容预测和自由生成，`content_metrics.py` 汇总指标，`allocations.py` 计数完整成本，`free_token_diagnostic.py` 复现生成分歧，`content_review.py` 审核，`content_plot.py` 作图。下文“映射检查”“内容探针”“冻结分配”“完整验证”对应 `research/phase1/experiments/static_layer_allocation/results/{qwen,llama}/` 下的 `mapping.json`、`probe.json`、`allocations.json`、`gate.json`；离线参数来源为同目录 `calibration.json`，“单层与叠加诊断”为 Llama 的 `single_layer.json`，“生成分词复现”为 Qwen 的 `free_token_diagnostic.json`。统一审核与执行来源见结果目录的 `review.json`、`execution.json`，历史结果、完整输入及服务器 logits 由 `research/phase1/source_index.json` 追溯。

本轮全部内容指标使用新的独立映射重算。模型权重、激活与共同 prefill 为 BF16，decode 注意力使用阶段共同 FP32 路径；输出 logits 保存为 FP32，NLL、差距、相对误差和词表 KL 在 FP64 中计算。每题共用高精度 prefill 源值，各方案独立建立缓存，teacher forcing 和自由生成分别持续更新各自的量化状态。审核逐项复算题内与题间汇总、冻结位宽和成本，并从服务器保留的全部 16 题原始 logits 复算单层及叠加指标。

## 实验目的

第一项实验在三种格式下固定共同高精度轨迹中的 query、层输入与 V4，测量每层 K 从 INT8 降到 INT4 的注意力输出变化；随后用独立校准题形成敏感度与重建排名。第二项实验在全部层同时量化时比较三档预算的六种策略，主判据为验证题均内容 NLL：敏感度策略须严格低于全部三个随机策略，并分别比较重建与反向策略。内容 KL、正确 token 差距、首内容 token 损失和自由生成完整答案准确率一起记录。局部指标描述扰动幅度，单层诊断检验边际影响，完整策略与生成测量检验组合效果。

Qwen 为 28 层，K4 层数为 2、7、14；Llama 为 32 层，对应 2、8、16。每模型使用冻结 C 的 32 道检索题，校准折与验证折各 16 题，均覆盖 2K/4K、四个目标深度及低/高干扰；题目为独立统计单位。三种条件为在线 per-token pre-RoPE、在线 per-token post-RoPE（H=0），以及离线 per-channel pre-RoPE（H=8、R=128）；V 主存均为在线 per-token INT4。离线 K4/K8 参数只用校准折的 32 道数学题与 16 道新检索题拟合。六种策略均只选择 K 层，残留另行记录并计入成本。Llama 在线 post、H=0 补测全部 32 个单层配置及全部 18 个预算组合的 logits 叠加。

## 实验结果与结论

### 不同表示下 Key 降位宽的层间代价

旧 C 的两个模型各 32 条检索记录中，key 与正确 value 的十六进制后缀全部相同，干扰 value 也保留共同后缀。新清单把 key、正确 value 和各干扰 value 分别随机生成，题内所有后缀互异。八组配对只改变上下文目标 value，query key 与模型各自的完整输入 token 长度保持不变。另在对应旧输入中删除目标行，检查输出是否仍含旧正确后缀。

映射检查使用 BF16 贪心生成，预算为 32 token；表中单位为题/对，完整答案直接匹配，后缀命中单独核对保存的预测文本。

| 模型 | 新原映射正确 | 新替换映射正确 | 两份均随映射正确 | 删旧目标后完整答案命中 | 删旧目标后仍含共同后缀 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Qwen | 7/8 | 8/8 | 7/8 | 0/8 | 7/8 |
| Llama | 3/8 | 4/8 | 3/8 | 0/8 | 4/8 |

Qwen 有 7 对、Llama 有 3 对的两份答案都正确跟随目标映射变化。旧输入删除目标行后，两模型均没有输出完整旧答案，但分别有 7/8、4/8 的输出仍含共同后缀。例如查询 `key-60be5790` 对应旧答案 `val-60be5790`，Qwen 在目标行已删除时生成 `val-60be5790-d0`。该控制显示共同后缀仍可由干扰项取得；新映射检查同时暴露 Llama 高精度检索基线的错误。所有冻结题目均保留。

对正确答案的实际 token 序列，$T_i$ 取字符跨度与 `val-` 后内容重叠的位置，跨边界 token 整体计入。产生 $y_t$ 的 query 使用 $y_{<t}$，先预测再喂入当前目标 token。共同高精度输出为 $o^{\mathrm{ref}}$，局部降位宽敏感度为

$$
S_\ell=\operatorname{平均}_i\operatorname{平均}_{t\in T_i}
\operatorname{平均}_{g\,\mathrm{有效}}
\frac{\|o^{K4V4}_{i,t,\ell,g}-o^{K8V4}_{i,t,\ell,g}\|_2^2}
{\|o^{\mathrm{ref}}_{i,t,\ell,g}\|_2^2}.
$$

$g$ 为 KV head 对应的 query head 组。K8 与 K4 均由共同源值直接量化，V4、RoPE 和近期副本固定；先对有效组归一化，再平均内容位置，最后对题目等权平均。零能量组按既定规则计数，无效量化按冻结停止条件处理。本轮没有触发无效量化或非有限输出停止。

为检验局部幅度能否预测实际边际影响，Llama 在线 post 的全层 K8V4 记为 $B$，仅第 $\ell$ 层降为 K4 的配置记为 $A_\ell$。正确前缀内容损失定义为

$$
L(A)=-\operatorname{平均}_i\frac{1}{|T_i|}
\sum_{t\in T_i}\log p_A(y_t\mid x_i,y_{<t}),\qquad
\Delta L_\ell=L(A_\ell)-L(B).
$$

同题记录内容位置 $D_{\mathrm{KL}}(p_B\Vert p_{A_\ell})$。还在 $B$ 自身的持续缓存和 query 下补测局部 $S$，与共同 BF16 校准轨迹的排序核对。以下均为独立验证 $n=16$ 的题均层排序；高敏感集合为最高 16 层。

| 排序对照 | Spearman 相关 | 高敏感集合重合 |
| --- | ---: | ---: |
| 校准局部 S / 验证同背景局部 S | 0.981 | 16/16 |
| 校准局部 S / 单层 ΔNLL | -0.002 | 10/16 |
| 校准局部 S / 单层 KL(B‖Aℓ) | -0.175 | 8/16 |
| 同背景局部 S / 单层 ΔNLL | 0.022 | 10/16 |
| 同背景局部 S / 单层 KL(B‖Aℓ) | -0.111 | 8/16 |

局部排名从校准轨迹到验证同背景轨迹保持相关 0.981，最高 16 层完全重合；但同背景局部 $S$ 与单层 ΔNLL、KL 的相关仅为 0.022、−0.111。第 1 层局部 $S$ 最高，却对应很小的边际 KL；第 5 层产生最大的损失增加和边际 KL，第 15 层的边际 KL 较高而 ΔNLL 为负。因此，Llama 的不一致已出现在单层端到端影响上，局部扰动幅度排序没有转化为边际预测代价排序。

## 总结

独立随机映射修复了共同后缀结构，配对与删目标控制给出了模型行为证据。内容位置测量显示 Qwen 在线有极高代价层，低敏感度分配能够避开严重失败，但只在离线三档通过严格随机 NLL 比较；Llama 仅在线 post 的 8 层档通过。Llama 局部排序在同背景下稳定，却几乎不预测单层边际 NLL/KL；多层 logits 叠加也偏离实际组合。真实生成另揭示了正确前缀内容测量与自由生成分词分支的差异。本轮留下三格式独立排名、三个预算的冻结位宽表、完整成本、全层内容分布与生成结果、全部单层和组合诊断，并保留失败工作点。

下一项验证接收新独立映射、三种格式、固定 V4、对应近期副本规则及三档仅 K 侧预算；BF16、同输入 KV8、同格式 K8V4、重建、反向和随机对照已经建立。本轮保留 Qwen 离线三档及 Llama 在线 post 8 层的方案级正比较，同时保留完整负比较与生成边界。进入 V 的格式、预算、策略数量和扩样规则另行冻结，待检验的是这些分配能否在独立真实生成中保持完整答案质量，以及内容预测改善能否跨过已观察到的生成分支错误。
