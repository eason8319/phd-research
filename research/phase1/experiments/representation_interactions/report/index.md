# 位宽与表示交互

本文回答 K8V4 相对 K4V8 的局部输出误差优势是否稳定，以及分数扰动如何经过注意力概率和 Value 影响输出。更新日期为 2026-09-30。结论范围是固定 query 的逐层注意力输出，不覆盖自由生成准确率、长上下文迁移或服务收益。

来源说明：协议和测量方法见 `research/phase1/guide.md` 与 `research/phase1/configs/`；执行代码根目录为 `research/phase1/experiments/representation_interactions/code/`，入口为 `evaluate.py`，指标定义为 `metrics.py`，统计与导出为 `results.py`。正式结果根目录见文首 YAML，每模型仅有 `summary.json` 与 `samples.json`：前者合并冻结主矩阵、新配对指标、来源和审核记录；后者每模型保存 384 条题目级配对评分。完整逐层和位置对明细留在服务器，由 `paired_diagnostic.provenance` 中的路径、SHA256、代码校验值及 `review.detail_checks` 索引。

冻结主矩阵使用完整键匹配的检索题面，来源提交为 `6ca63fd`；其 17 格数值、容量及当时的候选选择记录保持原值。本次补测为配对传播诊断，代码提交 `0894453615c918e4d7e8656f0f5642cab152587b`。作业 `20714` 在 `node7` 的 RTX 4090 上顺序完成两模型，退出码为 0，耗时 41 分 11 秒。权重配置保持 BF16；QKV 捕获与参考输出为 FP32，解释分数、概率和输出为 FP64。每组新测量内部共享同一次捕获；两次运行的轨迹未逐元素对照，不能把新旧差异只归因于 FP64。配对传播诊断的三种总输出误差与冻结主矩阵的最大绝对差为 Qwen $5.218\times10^{-4}$、Llama $2.467\times10^{-4}$，排序保持一致。

## 实验目的

比较相同名义位宽预算的 K8V4 与 K4V8，检查 Key 离线 per-channel／在线 per-token 和 pre／post-RoPE 四种条件。主判据是注意力输出相对平方误差；机制判据是共同 KV8 参照下的 K/V 增量、概率变化及输出传播预测。位置翻转仅作辅助诊断，不作独立的敏感性判据。

每模型使用冻结 C 集 96 题：64 道数学题、32 道检索题，两折各 48 题。Qwen 有 28 层、28 个 query head；Llama 有 32 层、32 个 query head。离线参数在互补折拟合。每层独立干预，误差不向后传播；query 为高精度轨迹中的首个生成 token，历史含该 token。Value 均采用当前在线 per-token 配置，只有保留的 Value 分组对照例外。

### 输出误差差异的传播分析

主矩阵已给出 K8V4 的输出误差小于 K4V8 的结果。以下以共同 KV8 参照分离两路降位宽增量，再结合分数、概率与输出的实测指标，分析这一差距的传播路径及其逐层分布。

令 $o_{88}$、$o_{48}$、$o_{84}$ 分别为同一次捕获下的 K8V8、K4V8、K8V4 输出，$o_{\mathrm{ref}}$ 为高精度参考。记 $\delta s=s_4-s_8$、$p_8=\operatorname{softmax}(s_8)$、$p_4=\operatorname{softmax}(s_4)$。对单个 query head，固定 V8 或固定 K8 时的输出增量分别为

$$
\delta o_K=o_{48}-o_{88}=V_8^\top(p_4-p_8),\qquad
\delta o_V=o_{84}-o_{88}=(V_4-V_8)^\top p_8.
$$

K 降位宽通过注意力概率的重新分配改变输出，V 降位宽则在同一组概率下改变被加权的内容。两式本身不保证哪一路增量更大：K 路取决于实际分数扰动、基准概率与 Value 内容差异，V 路取决于实际 Value 残差及其加权结果，须用配对测量比较。整层输出由各 head 拼接，以共同参考能量定义

$$
D_K=\frac{\|\delta o_K\|^2}{\|o_{\mathrm{ref}}\|^2},\qquad
D_V=\frac{\|\delta o_V\|^2}{\|o_{\mathrm{ref}}\|^2}.
$$

记 $E_{48}=\|o_{48}-o_{\mathrm{ref}}\|^2/\|o_{\mathrm{ref}}\|^2$，$E_{84}$ 同理。将总误差写成 KV8 基线误差与增量之和，展开平方范数可得

$$
E_{48}-E_{84}
=D_K-D_V+
\frac{2(o_{88}-o_{\mathrm{ref}})^\top(\delta o_K-\delta o_V)}
{\|o_{\mathrm{ref}}\|^2}.
$$

交叉项用于核对总误差差距是否主要来自两路增量，避免将 KV8 的基线误差计入降位宽效应。

进一步看 K 路的传播，softmax 的精确关系为

$$
p_{4,i}=\frac{p_{8,i}\exp(\delta s_i)}
{\sum_jp_{8,j}\exp(\delta s_j)}.
$$

所有分数增加相同常数时，概率不变，因此真正影响概率的是位置间的相对分数变化。令 $\mu=\sum_i p_{8,i}\delta s_i$，加权方差 $W=\sum_i p_{8,i}(\delta s_i-\mu)^2$。由上式可得

$$
D_{\mathrm{KL}}(p_8\|p_4)
=\log\sum_i p_{8,i}\exp(\delta s_i-\mu)
\approx \frac{W}{2}.
$$

近似式来自中心化扰动足够小时的二阶展开，加权一阶项为零；偏离该关系反映高阶项的影响。softmax 在 $s_8$ 处的雅可比为 $J_8=\operatorname{diag}(p_8)-p_8p_8^\top$，因此小扰动下 $\delta p_i\approx p_{8,i}(\delta s_i-\mu)$。代入输出关系，得到

$$
\widehat{\delta o_K}
=\sum_i p_{8,i}(v_{8,i}-o_{88})\delta s_i,
\qquad o_{88}=\sum_i p_{8,i}v_{8,i}.
$$

该式把分数扰动、概率权重和 Value 相对当前输出的内容差异联系起来。相同的分数扰动可以因概率与 Value 内容不同而产生不同的输出增量，不能仅凭分数残差大小或是否经过 softmax 判断 K/V 敏感性。精确关系与局部展开均不需要高斯或独立噪声假设；近似能否用于当前条件，仍需实测检验。

用 $E_{\mathrm{pred}}=\|\widehat{\delta o_K}-\delta o_K\|^2/\|o_{\mathrm{ref}}\|^2$ 和 $\rho=\overline E_{\mathrm{pred}}/\overline D_K$ 衡量汇总预测残差，同时记录预测与实测增量的余弦 $c$。$\rho$ 越小、$c$ 越接近 1，才越支持一阶传播解释。以下输出指标均先合并整层全部 head 的能量再归一化。

## 总结

本实验在两模型的四种表示条件下均观察到 K8V4 的局部输出误差小于 K4V8。配对测量将误差差距定位到 K 路的概率重分配与 Value 重加权，Qwen 在线条件的主要失真及一阶预测偏差集中在首尾层。结合两模型的误差与容量结果，后续共同保留离线 per-channel／在线 per-token × pre／post-RoPE 的四种 K8V4，不在本阶段依据局部误差细小排名选定生成能力最强的表示。

当前证据来自固定 query 的逐层局部干预，尚不能确定自由生成质量。下一项“真实生成与误差来源”实验在两个模型上用同一四种候选，与高精度、KV8 和 KV4 对照，每模型共 7 个配置，在短生成与 32K 任务中检验误差优势是否迁移。已有生成结果未覆盖全部四种，须补齐后再按任务质量与容量选择后续诊断的表示，并结合近期高精度残留与生成轨迹分析范围失配及误差累积。
